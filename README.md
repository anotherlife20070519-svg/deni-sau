# Дені саудың — жаны сау

Сайт о лекарственных растениях Сыр-Дарьинского региона на казахском языке. Сделан для областного конкурса «Қазақ тілін қолдануға арналған IT өнімдер».

## Структура

- `index.html` — главная: растения, история, способы приготовления, карта и санаторий, словарь, тест, источники.
- `plant.html?id=...` — страница растения: описание, рецепты по шагам, история и язык, предостережения, источники.
- `js/data.js` — **весь текст сайта**. Чтобы исправить формулировку, правьте только этот файл.
- `js/app.js`, `js/plant.js` — логика страниц.
- `css/style.css` — оформление.

## Как открыть на компьютере

```
python -m http.server 8765
```

Затем откройте http://localhost:8765 в браузере.

## Как опубликовать (GitHub Pages, бесплатно)

1. Создайте аккаунт на github.com и новый публичный репозиторий, например `deni-sau`.
2. Загрузите в него все файлы этой папки (Add file → Upload files).
3. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты сайт будет доступен по адресу `https://ВАШ-ЛОГИН.github.io/deni-sau/`. Эту ссылку и нужно указать в заявке.

После правки файлов увеличьте номер `?v=4` в `index.html` и `plant.html`, чтобы браузеры не показывали старую версию.

## Источники

Медицинские сведения взяты из монографий ВОЗ (WHO monographs on selected medicinal plants) и Европейского агентства лекарственных средств (EMA/HMPC), а также из рецензируемых обзоров с PubMed. Распространение растений — по «Флоре Казахстана». Иллюстрации — Wikimedia Commons: общественное достояние или открытые лицензии, автор и лицензия указаны под каждой картинкой.
